# Masters

Окремий гаражний мод для World of Tanks, який показує пороги знаків класності та прогрес мітки.

## Що залишено

- гаражна панель;
- актуальні пороги 3-го, 2-го, 1-го ступеня та «Майстра»;
- пороги мітки;
- поточний відсоток мітки;
- графік динаміки мітки;
- пам’ять завершених випадкових боїв;
- кеш API-даних, історії, положення та режиму панелі.

## Чого немає

- бойової панелі;
- live-damage hooks;
- бойової мітки та її стилів;
- післябойового progress badge;
- окремого конфіг-файлу.

`Masters` можна встановлювати одночасно з `Marks`.

## Збірка

```bash
python build.py --distribute
```
