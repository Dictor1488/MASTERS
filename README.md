# Masters

Окремий мод для World of Tanks, який показує прогрес до знаків класності.

## Можливості

- панель прогресу в гаражі;
- актуальні пороги 3-го, 2-го, 1-го ступеня та «Майстра»;
- графік історії прогресу;
- кешування отриманих даних;
- без міток на стволі;
- без застарілої панелі результатів;
- без бойових damage hooks, щоб не конфліктувати з `Marks`.

## Збірка

```bash
python build.py --distribute
```

## Налагодження

```bash
python tools/debug_check.py
```

`Masters` можна встановлювати одночасно з `Marks`.
