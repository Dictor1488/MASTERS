# Masters

Ангарний мод для World of Tanks, який показує актуальні пороги знаків
класності та відміток для вибраного танка.

Інтерфейс повністю працює через **GameFace**. Legacy Flash/Scaleform та AS3
рендерер з проєкту видалені.

Панель працює тільки в головному ангарі та автоматично оновлюється після
вибору іншого танка.

## Що показує панель

- поріг третього ступеня;
- поріг другого ступеня;
- поріг першого ступеня;
- поріг «Майстер»;
- пороги відміток 65%, 85%, 95% і 100%.

Дані порогів завантажуються з офіційного API World of Tanks і зберігаються
в локальному кеші. Термін актуальності кешу — три доби.

## Три режими

Клік по панелі перемикає режими по колу:

1. майстри + мітки;
2. майстри;
3. мітки.

Вибраний режим зберігається між запусками гри.

## Керування

- клік по панелі — перейти до наступного режиму;
- перетягування панелі — змінити її положення.

Положення панелі також зберігається між запусками.

## Умови відображення

Панель:

- відображається тільки в кореневому екрані ангару;
- працює для танків V рівня та вище;
- тимчасово не зникає під час швидкого перемикання танків;
- ігнорує застарілі відповіді API для раніше вибраного танка;
- відновлюється після повернення в ангар із бою.

## Збережені дані

Мод зберігає:

- кеш порогів майстерності та відміток;
- службову історію зміни відмітки;
- положення GameFace-панелі;
- вибраний режим.

Файл кешу розташовується в каталозі налаштувань клієнта:
`mods/mastery/cache.dat`.

## Склад проєкту

- `python/gui/mods/mod_under_pressure_mastery.py` — контролер ангару,
  отримання даних, кеш та історія;
- `python/gui/mods/mod_under_pressure_mastery_gameface.py` — GameFace/Wulf renderer
  і зв’язок із контролером;
- `resources/in/gui/gameface/mods/under_pressure/mastery` — HTML/CSS/JS GameFace;
- `resources/in/mods/configs/res_map/UnderPressureMasteryGamefaceView.json` — реєстрація layout;
- `resources/in/mods/under_pressure.mastery` — українська, англійська та російська локалізації;
- `build.py` — пакування мода у формат `.wotmod`.

У релізному workflow більше немає Apache Flex, playerglobal або компіляції SWF.
